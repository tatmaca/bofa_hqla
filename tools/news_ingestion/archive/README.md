# Archive Directory

This directory contains old, unused, or deprecated files kept for reference.

## Structure

- `old_scripts/` - Old or unused Python scripts
- `old_configs/` - Backup or alternative configuration files
- `old_docs/` - Deprecated documentation files

## Files Archived

### Old Scripts
- `export_last24.py` - Old export utility (replaced by database queries)
- `create_training_all_dates.py` - Old training data creation script
- `collect_weekend_news.py` - Replaced by catch_up_missing_data.py
- `collect_dates.py` - Utility script, kept for reference
- `collect_training_data_simple.py` - Simplified version, kept for reference
- `training_pipeline.py` - Old pipeline script

### Old Configs
- `news_config.yaml.backup` - Backup of previous configuration
- `news_config_enhanced.yaml` - Alternative configuration (not used)

### Old Docs
- `IMPROVEMENTS_SUMMARY.md` - Summary of improvements (integrated into main docs)
- `OPTIMIZATION_COMPLETE.md` - Optimization completion summary
- `OPTIMIZATION_SUMMARY.md` - Optimization summary (integrated into main docs)

## Note

These files are kept for historical reference and should not be used in the active pipeline.
