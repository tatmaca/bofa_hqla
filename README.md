2025 University of Chicago MSFM Project Lab
Bank of America HQLA Risk Optimization

This repo contains the infrastructure for an AI monitoring agent
with the capacity to:

- Injest real-time market, macro, and news data
- Generate portfolio reallocation suggestions
- Simulate risk events and expected portfolio impacts
- Among other features

Subdirectories feature code which allows us to:

- Scrape data from various reputable sources
- Generating models for key bank risk metrics (e.g. NII)
- Forecast risk scenarios using SotA statistical models
- Among other features

This project is led by Amit Pandey and Adam Ashcraft at Bank of America
and overseen by Professor Amitabh Chaudhary at the University of Chicago.

The student collaborators on this project are Aryaa Gunavante, Charles
Benello, Josh Li, Togay Atmaca, and Xiangchen Liu.
